## Source-supported details

The documentation describes Khipu as an interactive visualisation for RIPE Atlas traceroute, DNS, and ping measurements, with IP, ASN, and country views, path filters, RTT filters, and export options. It says location is inferred using IPLocate, PeeringDB, and RIPE Registry sources and warns that IP geolocation can be wrong, especially for CDNs. It also documents URL sharing of view settings and filters (official Khipu docs, “Overview,” “Supported Measurement Types,” “View Modes,” and location note).

## Use and limits

**Researcher inference:** Khipu is a measurement-inspection and presentation aid; its view of a path depends on the underlying RIPE Atlas probe data and enrichment sources. A plotted country/ASN label is not ground truth for physical routing or user experience. Its use in this project would support inspecting network context, not validate browser performance scores.
