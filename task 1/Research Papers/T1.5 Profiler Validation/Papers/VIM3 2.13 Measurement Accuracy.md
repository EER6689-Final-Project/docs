# JCGM VIM3 §2.13 — Measurement Accuracy

- **Citation:** Joint Committee for Guides in Metrology (JCGM), *International Vocabulary of Metrology — Basic and General Concepts and Associated Terms (VIM3)*, entry 2.13, “measurement accuracy.” [Current entry](https://jcgm.bipm.org/vim/en/2.13.html).
- **Zotero key:** `AAW3TPVK` (webpage; HTML snapshot attached).
- **Source access:** Online VIM3 entry and Zotero snapshot checked 13 October 2026.

## Outline Summary

- **Definition:** Accuracy is closeness of agreement between a measured value and the true value of a measurand. VIM says accuracy is qualitative, not a quantity to which a numerical value is assigned.
- **Distinctions:** The entry warns against using accuracy as a synonym for either trueness or precision; accuracy relates to both. It also notes historical variation in how authors use the term.
- **Project relevance:** A profiler’s agreement with Lighthouse or DevTools cannot by itself be called “accuracy” unless the target quantity and a defensible reference are specified. Agreement, repeatability, and bias should be reported as distinct properties.
- **Limit:** This vocabulary entry defines metrology terms; it does not prescribe a browser-profiler validation protocol or establish a truth source for web-performance measurements.

## T1.5 Evidence Check

- **Source-supported:** VIM3’s definition and cautions about numerical accuracy, trueness, and precision.
- **Researcher inference:** Use “agreement with the reference implementation” for pairwise comparisons unless an independently justified reference value exists.
